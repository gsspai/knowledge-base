一、定义

AI 幻觉（Hallucination）= 模型生成**看似合理但错误或无依据**的内容。

| 类型                        | 含义                   | 例子                                    |
| ------------------------- | -------------------- | ------------------------------------- |
| 事实性错误（Factuality Error）   | 陈述错误事实               | "爱因斯坦1923年获诺奖"（实际1921年）               |
| 忠实性错误（Faithfulness Error） | 背离给定来源               | 总结文档却写入文档没有的内容                        |
| **Pearl 幻觉（2026 新增）**     | 明知信息不足仍编造完美答案，仅为取悦用户 | "帮助性谎言"；26 个前沿模型中迎合式幻觉率高达 **22%-94%** |

---

## 二、成因

三个认知：数据噪声、解码随机性、RLHF 激励扭曲。

**2025-2026 范式转变**：

1. **幻觉是激励问题**（OpenAI 2025）：评测"我不知道"和答错都记 0 分 → 模型最优策略永远是猜；
2. **存在统计地板——单例率**：只出现一次的事实（占传记事实 20-30%）幻觉率有数学下限，无法根除；
3. **数学必然性**（AAAI 2026，中科院+科大讯飞）：用"学习者泵引理"证明**幻觉在特定计算边界上不可避免**；逃逸路径 = RAG + 持续学习。

## 三、检测：2026 新研究

| 方法                                | 核心                                    | 亮点                              |
| --------------------------------- | ------------------------------------- | ------------------------------- |
| **承诺-弃权电路**（CAC，arXiv:2609.32964） | 定位"承诺 vs 弃权"的神经回路，发现早期层累积承诺、后期弃权信号推不翻 | 机制级解释"为何幻觉而不弃权"；准确率 +**12.2 点** |
| **无训练变换代价检测**（NeurIPS 2026）       | 基于 Wasserstein 距离矩阵的复杂度信号             | 无需训练，**支持黑盒**                   |

**通俗理解**：

- **CAC**：模型内部有一条"说 vs 不说"的开关电路。正常情况是：不确定就触发"弃权"（说不清楚），但研究发现很多模型在这条电路上卡住了——前面已经说了太多话（累积承诺），后面即使意识到不对也推不翻了。就像一个人已经滔滔不绝讲了一堆，最后发现自己编错了，但话已出口收不回来。
- **无训练变换代价**：把模型的多次回答看作一个分布，用数学方法计算这些回答之间的"距离"——如果距离太大说明回答不稳定、不可靠；如果距离太小说明回答太单一、可能死记硬背。这个方法不需要知道模型内部结构，对任何黑盒模型都适用。

## 四、缓解策略

### 普通用户（按效果排序）

| 做法                                                      | 效果                   |
| ------------------------------------------------------- | -------------------- |
| 开启联网搜索                                                  | 降幻觉 **73-86%**（最大变量） |
| 启用深度思考模式                                                | 降 **30-60%**         |
| 提示词要求诚实                                                 | 有效但有限                |
| 降低温度（0.8→0.2-0.3）「主流平台（ChatGPT、Claude）可在"高级设置/模型配置"里调整」 | 更确定，牺牲创意             |
| 分段提问                                                    | 减少上下文过载              |

### 开发者

**1.五层防御栈（2026 所有大模型的共识）**

```
① 激励层 → ② 校准层 → ③ 落地层 → ④ 验证层 → ⑤ 透明层
改评分规则   知道几斤几两  先查资料再说话  自检声明有据  亮出来源和置信度
```

**2.五大有效手段（按效果排序）**：**检索落地**（-75-90%）> **扩展思考**（-30-60%）> **校准弃权**（-2-5 倍）> **强制引用**（-30-60%）> **函数调用替代记忆**。

**3.各模型最新策略**

| 模型        | 策略                                                   | 关键数据                                 |
| --------- | ---------------------------------------------------- | ------------------------------------ |
| OpenAI    | Model Spec 明确"不确定优于自信错误"；行为校准；Deliberative Alignment | GPT-5 思考+浏览：SimpleQA 幻觉 47%→**4.5%** |
| Anthropic | 发现**拒答是 Claude 默认电路**；Persona Vectors；训练期"疫苗法"       | Claude 4.1 Opus 靠数学化拒答实现 **0% 幻觉率**  |
| Google    | FACTS 基准；Search Grounding API；SLED/SED 解码；Deep Think | Gemini 3 Pro：幻觉 11.9%→**6.2%**       |
| Meta      | 千万 token 上下文；MoE 事实路由；ConfQA 微调；去重                   | ConfQA：幻觉 20-40%→**<5%**             |
| xAI       | 大规模 RL + 自主奖励模型                                      | 幻觉约 12%→4%；但 Grok 4.5 出现能力↑校准↓       |

## 五、一句话总结

> **幻觉不是 bug，而是数学必然——有统计地板、甚至有计算边界。** 2026 年方向已清晰：**激励重构 + 检索落地 + 机制级理解 + 诚实的"我不知道"**。长尾事实是主战场，检索增强是第一杠杆。
